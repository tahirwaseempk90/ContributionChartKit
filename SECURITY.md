# Security Policy

ContributionChart is a user interface library. It makes no network requests, stores no data, and has no third-party dependencies, so its exposure is small. Reports are still welcome.

## Supported versions

Fixes are made on the latest release. Please update to it before reporting a problem.

## Reporting a problem

Please don't describe a security problem in a public issue.

Use GitHub's private reporting: on the repository's **Security** tab, choose **Report a vulnerability**.

If that option isn't there, open an issue asking for a private way to get in touch, without including any details of the problem.
