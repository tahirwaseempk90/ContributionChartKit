# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com), and the project uses
[Semantic Versioning](https://semver.org).

## [1.0.0] - 2026-11-03

First release.

### Added

- `ContributionChart`, a responsive SwiftUI chart of positive and negative values around a zero baseline.
- Proportional, symmetric, and fixed scales.
- Optional title, baseline, markers, stems, labels, value axis, reference lines, shaded regions, and
  category ticks.
- Label placement that avoids overlaps, keeping the labels of the largest values.
- VoiceOver support with a spoken summary, an element for each point, and an Audio Graph.
- Dynamic Type, right-to-left layout, and light and dark appearances.
- Support for iOS, iPadOS, Mac Catalyst, macOS, tvOS, watchOS, and visionOS.
